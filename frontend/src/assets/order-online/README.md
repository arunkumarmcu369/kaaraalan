# Drop product bottle images here

Name each file after the product `imageKey` from `src/constants/orderOnlineProducts.js`:

- paneer.png
- lemon.png
- orange.png
- blueberry.png
- ginger.png
- nannari.png
- grape.png
- pineapple.png

Supported: `.png`, `.jpg`, `.jpeg`, `.webp`

The Order Online page picks them up automatically; no code changes needed.
